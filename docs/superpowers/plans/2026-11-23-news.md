# News Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Administrators write news posts (banner, title, markdown with images and app links) in Coffer.Manager; users read them in Community › News; the app can share an app link of items, listings, collections and profiles.

**Architecture:** `news_posts` table + `NewsService` (admin CRUD / publish / images / link-target search, audited) and a read-only app endpoint for published posts. Images in `IMAGESTORE_PATH/news`, re-encoded with ImageSharp, served by an anonymous endpoint and referenced in markdown as `coffer-image:{name}`. The app renders markdown with `@ronradtke/react-native-markdown-display@8.1.0` and resolves `coffer://` links through one pure parser + a resolver over the existing `open*` helpers. The Manager gets a News view with a markdown editor, toolbar and a markdown-it based preview.

**Tech Stack:** ASP.NET Core 8, EF Core, SixLabors.ImageSharp, xUnit; Expo / React Native, react-query, `@ronradtke/react-native-markdown-display` 8.1.0, i18next; Python / Tkinter / markdown-it-py / Pillow (Manager).

**Spec:** `docs/superpowers/specs/2026-11-23-news-design.md`

## Global Constraints

- Admin endpoints on `ManagerControllerBase`; every change → `AdminAudit.Add` (`news.create|update|publish|unpublish|delete|image`).
- App endpoints `[Authorize]`, published only; drafts and unknown ids answer the same 404 `newsNotFound`.
- Title 1–120 chars; content ≤ 50 000; hero / content image names must exist in the store; markdown HTML is never rendered (app library renders HTML tokens as text; Manager preview `html=False`).
- Images: PNG/JPEG/WebP by magic bytes, ≤ 8 MB, longest side resized to ≤ 1600 px, metadata stripped, JPEG q85 (PNG kept when it has an alpha channel), name `{guid:N}.jpg|png`; served by `GET api/News/Image/{fileName}` (anonymous, name regex `^[0-9a-f]{32}\.(jpg|png)$`, `nosniff`, `Cache-Control: public, max-age=604800`).
- `published_at` set on first publish only; `edited_at` set when title / banner / content change while published.
- App links: exactly the spec table (`coffer://item|collection|listing|user|news/{guid}` and the fixed pages); anything else → "can't be opened"; `https://` and `mailto:` → `Linking.openURL`.
- Share: React Native `Share.share({ message: link })` — no new native module.
- New routes classified in `RouteSweepTests` (not type-related / exempt with reason).
- Git: no branches, no pushes, no Co-authored-by trailers. Do not run prettier on existing files (no repo config; keep their style). Tests: backend `"/c/Program Files/dotnet/dotnet.exe" test src/Coffer/Coffer.Tests`; app `npm run test:unit`, `npx tsc --noEmit`, `npm run check:i18n`, `npm run check:errors`; Manager `venv\Scripts\python.exe -m unittest discover`.

## Review Focus

1. **A draft fetched by id from the app** — expected 404, never its content. Test `DraftsAreInvisibleToTheApp` (Task 1).
2. **Hostile markdown** (`<script>`, `javascript:` links, `coffer://item/not-a-guid`, unknown targets) — expected: nothing executes; such links show "can't be opened". Tests `UnsafeOrMalformedLinksAreRejected` (Task 3), Manager `test_preview_never_renders_html` (Task 5).
3. **An image shared by two posts** — deleting one keeps the image for the other. Test `DeletingAPostKeepsSharedImages` (Task 1).
4. **Edit after publish / unpublish and republish** — `edited_at` set, original `published_at` kept. Test `RepublishKeepsTheOriginalDate` (Task 1).
5. **Link picker searching hidden or deleted things** — not offered. Test `LinkTargetsSkipHiddenAndDeleted` (Task 2).
